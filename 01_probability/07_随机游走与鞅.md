# 07 随机游走与鞅（Random Walk & Martingale）

> 面试权重：★★★☆☆（对冲基金/自营高频）｜ 难度：高 ｜ 来源：[S7] 绿皮书；Tsay（随机过程章）
> 定位：从"静态概率"到"动态过程"。赌徒破产、公平游戏、期权对冲直觉都在这里。

## 教学

**简单随机游走**：S₀=i，每步 ±1，P(up)=p。

```
E[Sₙ] = i + n(2p−1)
Var[Sₙ] = n（对称时）；标准差 √n
```

对称游走：期望位置不动，但波动随 √n 增长——"随机性扩散"的直观模型。

**鞅（Martingale）**：E[Sₙ₊₁ | 历史] = Sₙ——给定现在，未来期望不赚不亏。

- 公平游戏 = 鞅；期权定价、对冲都在"构造鞅"。
- **可选停时**：有界停时下 E[S_τ]=E[S₀]（公平游戏在哪停都不占便宜）。

![赌徒破产](assets/gamblers_ruin.png)

**赌徒破产公式**：起始资金 i，目标 N，单局胜率 p，q=1−p：

```
公平 p=1/2:  P(赢到 N) = i/N，P(破产) = 1 − i/N
有偏:        P(破产) = ((q/p)^N − (q/p)^i) / ((q/p)^N − 1)
```

## 例题精讲

**例 1｜公平游戏到 0 或 10**：起始 5 → P(到 10)=1/2，P(破产)=1/2。无论玩多少次，期望不赚不亏。

**例 2｜有偏 p=0.6，起始 5，目标 10**：

```
q/p = 2/3
P(破产) = ((2/3)^10 − (2/3)^5) / ((2/3)^10 − 1) ≈ 0.083
```

微小优势 → 破产概率骤降（这就是为什么赌场只赚一点也稳赢）。

**例 3｜对称游走 100 步**：E[S₁₀₀]=0，但标准差 √100=10 → P(超出 ±20)≈4.6%（正态近似）。

## 面试题

**热身**

1. 对称游走 10 步的期望位置与方差？ → 0 与 10。
2. 鞅的定义？ → E[Sₙ₊₁|Fₙ]=Sₙ。

**核心**

3. 公平游戏 5 元赌到 10 元，破产概率？ → 1/2。
4. 为什么 p=0.51 就"稳赢"？ → 破产概率指数级下降（用公式说明）。
5. 对称游走首次回到 0 的期望时间？ → 无穷（虽然必返回）。

**进阶**

6. 用可选停时证明公平游戏？ → E[S_τ]=E[S₀]（τ 有界时）。
7. 反射原理是什么？ → 对称游走首次到达 a 后，路径与反射路径一一对应 → 首达时间分布。
8. 鞅与期权：为什么说对冲是"构造鞅"？ → 使组合价值在风险中性测度下为鞅 → 期望即价格。
