# 05 期望 · 方差 · 协方差矩阵

> 来源：[S2] Q7 协方差矩阵｜ [S7] Blitzstein & Hwang Ch7；Grinold & Kahn《Active Portfolio Management》
> 用途：组合风险计算的根基；因子去冗余、协方差收缩都从这里来。

## 概念

- **期望（线性）**：E[aX + bY] = aE[X] + bE[Y]。
- **方差**：Var[X] = E[X²] − E[X]²；Var[cX] = c²Var[X]。
- **两变量**：Var[aX + bY] = a²Var[X] + b²Var[Y] + 2ab·Cov(X,Y)。
- **协方差**：Cov(X,Y) = E[XY] − E[X]E[Y]。
- **相关系数**：ρ = Cov(X,Y) / (σx·σy) ∈ [−1, 1]（Cauchy-Schwarz 保证）。
- **协方差矩阵** Σ，第 (i,j) 元 = Cov(Xi, Xj)，对角元 = 方差。
- **样本协方差**：除以 n−1（无偏估计）。

## 组合公式（必背）

```
组合收益:      R_p = w'R
组合方差:      σ_p² = w'Σw
两资产特例:    σ_p² = w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρσ₁σ₂
等权 n 资产:   σ_p² → 平均协方差（n→∞ 时只剩协方差项，这就是分散化的数学）
```

## 金融应用

- **风险预算 / 组合构建**：w'Σw 是所有优化的目标之一。
- **因子去冗余**：因子间 IC 相关性高 → 合并或剔除（对应 QS工作台"去冗余"步骤）。
- **协方差估计**：样本协方差在 n 大时不稳定 → Ledoit-Wolf 收缩、EWMA、因子模型。

## 代码

```python
import numpy as np
rng = np.random.default_rng(1)
rets = rng.normal(0, 0.01, size=(252, 3))   # 3 个资产 252 天
cov = np.cov(rets.T)                        # 3x3 样本协方差（除 n-1）
w = np.ones(3) / 3
port_var = w @ cov @ w
print("组合日方差:", round(port_var, 8))
print("组合年化波动:", round(np.sqrt(port_var * 252) * 100, 2), "%")
```

## 面试题

1. 两个资产各占 50%，σ₁=20%、σ₂=20%、ρ=0.5，组合波动？ → √(0.25×0.04+0.25×0.04+2×0.25×0.5×0.04) = √0.03 ≈ 17.3%。
2. 为什么样本协方差除以 n−1？ → 使 E[样本方差] = 总体方差（无偏），因为均值本身也是估计的。
3. 相关系数为什么 ≤1？ → Cauchy-Schwarz：|Cov| ≤ σx·σy。
4. 等权持有 n 个不相关资产，n→∞ 组合方差？ → 0（只剩平均方差/n → 0）。
