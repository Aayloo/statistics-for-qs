# 04 期望、方差与矩方法

> 面试权重：★★★★★（高产的技巧题）｜ 难度：中 → 高 ｜ 来源：[S7] Blitzstein & Hwang Ch7、绿皮书
> 定位：概率题里最能拉开差距的技巧区——**线性期望 + 指示变量 + 对称性**能秒杀大部分难题。

## 一、教学

### 1.1 数学期望的定义

**定义**：离散型

$$E[X] = \sum_{i} x_i\,p_i \qquad \text{（绝对收敛时）}$$

连续型

$$E[X] = \int_{-\infty}^{\infty} x\,f(x)\,dx$$

期望是以概率为权的加权平均，也叫均值。

### 1.2 线性性质（最重要）

**定理**：

$$E[aX + bY] = aE[X] + bE[Y]$$

> 注：**不需要独立性**——线性期望永远可拆。

### 1.3 方差

**定义**：

$$\mathrm{Var}(X) = E\big[(X - E[X])^2\big] = E[X^2] - \big(E[X]\big)^2$$

$$\mathrm{Var}(aX + bY) = a^2\mathrm{Var}(X) + b^2\mathrm{Var}(Y) + 2ab\,\mathrm{Cov}(X,Y)$$

### 1.4 指示变量（Indicator）

**定义**：

$$I_A = \begin{cases} 1, & \omega \in A \\ 0, & \text{否则} \end{cases}, \qquad E[I_A] = P(A)$$

技巧：把"期望个数"拆成"每个位置发生概率之和" E[Σ Iᵢ] = Σ P(Aᵢ)——相关性完全不影响。

### 1.5 对称性

随机排列中两个对象地位可交换 → 各自的"先后概率"各 1/2，无需计算。

### 1.6 Jensen 不等式

**定理**：g 为凸函数时

$$E[g(X)] \ge g\big(E[X]\big)$$

特例：E[X²] ≥ (E[X])²。

### 1.7 尾部和公式（高频技巧）

**定理**：X 取非负整数值时

$$E[X] = \sum_{k=1}^{\infty} P(X \ge k)$$

X ≥ 0 连续时

$$E[X] = \int_0^{\infty} P(X > x)\,dx$$

> 用处：几何分布期望、次序统计量、集卡问题都能一行推出来——"期望 = 尾部概率之和"。

**例 5｜用尾部公式推几何分布期望**

X ~ Geometric(p)，P(X ≥ k) = (1-p)ᵏ⁻¹：

$$E[X] = \sum_{k=1}^{\infty}(1-p)^{k-1} = \frac{1}{p}$$

## 二、例题精讲

**例 1｜洗牌固定点（指示变量经典）**

52 张牌随机排列，X = 位置与牌面号相同的个数：

$$X = \sum_{k=1}^{52} I_k, \qquad E[I_k] = \frac{1}{52} \ \Rightarrow \ E[X] = 52 \times \frac{1}{52} = 1$$

与牌数无关——永远期望 1 个固定点。

**例 2｜掷骰子直到出现 6**

X ~ Geometric(1/6)：

$$E[X] = \frac{1}{1/6} = 6$$

**例 3｜随机排列中 A 站在 B 前？**

对称性 → 1/2；三人相对顺序中 A 在 B 前且 B 在 C 前 → 1/6。

**例 4｜两个独立 U(0,1) 的最大值期望**

先用分布函数：

$$P(\max \le x) = x^2 \ \Rightarrow \ E[\max] = \int_0^1 (1 - x^2)\,dx = \frac{2}{3}$$

推广：n 个均匀随机数的最大值期望 n/(n+1)（见 [05 章](05_联合分布协方差与条件期望.md) 配图）。

## 三、面试题

**热身**

1. 公平骰子 E[X], Var(X)？ → 3.5 与 35/12。
2. E[X²] 与 (E[X])² 谁大？ → Jensen：E[X²] ≥ (E[X])²。

**核心**

3. n 顶帽子错配的期望个数？ → 1（指示变量，与 n 无关）。
4. 掷到正面为止的期望次数？ → 2（几何 p=1/2）。
5. 两个 U(0,1) 的 max 期望？ → 2/3。

**进阶**

6. 圣彼得堡悖论：奖金 2ᵏ、概率 2⁻ᵏ，期望？ → E = Σ 2ᵏ · 2⁻ᵏ = ∞。
7. 用指示变量求"固定点方差"？ → 需要协方差项 Cov(Iᵢ, Iⱼ)，线性技巧到此失效——面试加分点。
8. 用尾部公式求非负随机变量期望？ → E[X] = ∫(0,∞) P(X>x) dx。
