# 07 整体检验（White's Reality Check / RAS）

> 面试权重：★★★☆☆ ｜ 难度：高 ｜ 来源：[S4 Ch16][S7]
> 定位：把"最优策略 vs 无预测力基准"当成一次正式的统计检验。

## 一、教学

### 1.1 White's Reality Check（白噪声现实检验）

检验"最好的策略是否显著优于零基准"：

1. 用 **bootstrap**（block bootstrap，保留序列相关）重抽样收益
2. 对每次重抽样，在所有策略里取最优绩效
3. 得到"纯噪声下的最优绩效分布"
4. 观测最优绩效 vs 分布 → p 值

> 与 DSR 互补：DSR 用解析近似，Reality Check 用重抽样。

### 1.2 RAS（Rademacher Anti-Serum）

对每次试验随机翻转信号符号（±1）→ 构造"同一套流程在噪声下的绩效分布"。

- 不依赖参数分布假设
- 直接度量"我这条流程随机翻信号能跑出多好"

### 1.3 严谨性协议（合起来用）

1. IC 显著（HAC t）→ 2. 无泄漏（purge/embargo）→ 3. CPCV 多条路径 → 4. DSR 校正试验次数 → 5. PBO 检查排名翻转 → 6. Reality Check / RAS 对噪声基准

## 二、例题精讲

**例 1｜Reality Check 步骤**

50 个策略，1000 次 block bootstrap：噪声下最优月夏普分布 90% 分位 = 0.8 → 观测最优 0.9 → p≈0.06 → 边缘。

**例 2｜RAS 直觉**

信号全部随机翻转符号跑 1000 次 → 最好伪策略夏普 1.8 → 你的真实策略 1.9 → 几乎不优于噪声流程。

**例 3｜组合使用**

一个因子：t=2.4（HAC）、CPCV 5 条路径全为正、DSR p=0.03、PBO=0.1、RAS p=0.04 → 可信度高，可以进入 paper track。

## 三、面试题

**热身**

1. White's Reality Check 检验什么？ → 最优策略是否优于噪声。
2. 为什么用 block bootstrap？ → 保留序列相关。

**核心**

3. RAS 怎么做？ → 随机翻转信号符号，看噪声绩效分布。
4. Reality Check 与 DSR 区别？ → 重抽样 vs 解析近似。
5. 严谨性协议的顺序？ → IC → 防泄漏 → CPCV → DSR → PBO → 基准检验。

**进阶**

6. Reality Check 的保守性？ → 对最优策略惩罚重，可能太严。
7. 什么时候信一个因子？ → 全套检验通过 + 经济逻辑 + 样本外稳定。
