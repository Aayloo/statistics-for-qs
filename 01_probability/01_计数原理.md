# 01 计数原理（Combinatorics）

> 来源：[S1] k3vv0 quant_interview_prep（Combinatorics 目录）｜ [S7] 绿皮书（Zhou）
> 用途：概率题的第一步——先把"事件有多少种"数对，概率才有正确的分母。量化面试的脑筋急转弯大多从这里起步。

## 概念

- **乘法原理**：一件事分 k 步，第 i 步有 n_i 种做法，则总数为 n_1 × n_2 × ... × n_k。
- **加法原理**：互斥的 k 类情况，总数为各类之和。
- **排列（有顺序）**：从 n 个里取 k 个排顺序：P(n,k) = n! / (n−k)!。
- **组合（无顺序）**：从 n 个里取 k 个：C(n,k) = n! / (k! · (n−k)!)，也叫"二项式系数"。
- **有放回抽取**：有序 n^k；无序（隔板法）C(n+k−1, k)。
- **鸽笼原理**：n+1 个物体放 n 个盒子，至少一个盒子有 ≥2 个物体。
- **容斥原理**：|A∪B| = |A|+|B|−|A∩B|；三集合类推（加奇减偶）。

## 核心公式速记

```
P(n,k) = n!/(n-k)!
C(n,k) = n!/[k!(n-k)!]
C(n,k) = C(n,n-k)
C(n,0)+C(n,1)+...+C(n,n) = 2^n
无放回有序: P(n,k)   无放回无序: C(n,k)
有放回有序: n^k      有放回无序: C(n+k-1,k)
```

## 金融 / 面试场景

- 扑克牌、骰子、抽样：算事件空间分母。
- 因子组合、投资组合选择：C(n,k) 表示从 n 个资产里选 k 个的组合数。
- 生日问题：n 人至少两人生日相同的概率 ≈ 1 − 365!/(365ⁿ·(365−n)!)。

## 面试题

1. 52 张牌发 5 张（不看顺序），有多少种？ → C(52,5) = 2,598,960。
2. 掷两枚骰子，和为 7 的概率？ → 6/36 = 1/6。
3. 23 人房间里，至少两人生日相同的概率约多少？ → ≈50%（鸽笼/互补事件）。
4. 有 10 个资产，选 3 个等权组合，多少种？ → C(10,3)=120。
