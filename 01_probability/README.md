> 目标：从"看得懂公式"到"能 2 分钟白板讲清推导"。
> 公式风格：全部使用 LaTeX（`$...$` / `$$...$$`），GitHub 直接渲染；每章按"教学 → 例题精讲 → 面试题 → 参考"组织。
