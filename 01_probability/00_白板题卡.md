# 01 模块 · 白板题卡（面试用）

> 用法：每题先自己 2 分钟口头答，再对答案要点。标 ★ 为高频。

## 计数（Combinatorics）

1. ★ 52 张牌发 5 张的组合数 → C(52,5)=2,598,960。
2. ★ 23 人至少两人生日相同 → ≈50%。
3. 掷两枚骰子点数和的分布，和为 7 概率 → 1/6。
4. 从 10 个资产选 3 个 → 120 种。

## 分布（Distributions）

5. ★ Binomial(100, 0.5) 期望与标准差 → 50 与 5。
6. ★ Poisson(λ) 期望=方差=λ；至少一次 = 1−e^(−λ)。
7. ★ 每日收益 N(0,1%)，年化波动 → ≈15.9%。
8. 对数正态的期望 E[e^(σZ)] → e^(σ²/2)。
9. t 分布 vs 正态：何时用 → 小样本、肥尾。

## 条件概率与贝叶斯（Bayes）

10. ★ 患病率 1%、敏感度 99%、假阳性 5%，阳性后真实患病 → ≈16.8%。
11. ★ Monty Hall 换门 → 2/3。
12. 双正面硬币题（随机取一枚抛出正面）→ 2/3。
13. 两孩子问题（至少一个男孩）→ 1/3。
14. 策略命中 60% vs 运气 50%，先验 10%，一次命中后 → ≈11.8%（几乎不变）。

## LLN / CLT

15. ★ 抛 100 次硬币，正面比例的近似分布 → N(0.5, 0.0025)。
16. ★ IC 的 t 统计为什么用 √T → CLT：SE = σ/√T。
17. 厚尾时 CLT 的风险 → 收敛慢；方差不存在则不适用。
18. 样本均值 95% 置信区间 → X̄ ± 1.96·σ/√n。

## 期望 / 方差 / 协方差

19. ★ 两资产 ρ=0.5 等权组合方差 → w'Σw。
20. ★ 为什么除以 n−1 → 无偏。
21. ★ 相关系数为什么 ≤1 → Cauchy-Schwarz。
22. 等权 n 个不相关资产，n→∞ 组合方差 → 0。

## 检查清单（面试前过一遍）

- [ ] 能默写贝叶斯公式并解释先验/似然/后验
- [ ] 能说出正态 68-95-99.7
- [ ] 能手推组合方差公式
- [ ] 能解释"为什么回测要看 t 统计和多重检验"
