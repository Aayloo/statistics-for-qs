# 04 期望、方差与矩方法

> 面试权重：★★★★★（高产的技巧题）｜ 难度：中→高 ｜ 来源：[S7] Blitzstein & Hwang Ch7、绿皮书
> 定位：概率题里最能拉开差距的技巧区——**线性期望 + 指示变量 + 对称性**能秒杀大部分难题。

## 教学

**三条主线**

1. **线性期望**：E[aX+bY]=aE[X]+bE[Y]——不需要独立性！
2. **指示变量**：I(A)=1{事件 A 发生}，E[I(A)]=P(A)。把"期望个数"拆成"每个位置概率之和"。
3. **对称性**：随机排列中两个对象位置可交换 → 概率各 1/2。

**公式表**

```
E[X]      = Σ x·P(X=x)（离散）｜ ∫x f(x)dx（连续）
Var[X]    = E[X²] − E[X]²
Var[aX+bY] = a²Var[X] + b²Var[Y] + 2ab·Cov(X,Y)
Cov(X,Y)  = E[XY] − E[X]E[Y]
Jensen:    E[g(X)] ≥ g(E[X])（g 凸）；≤（g 凹）
```

## 例题精讲

**例 1｜洗牌固定点（指示变量经典）**

52 张牌随机排列，求"第 k 张牌恰好是原位置"的期望个数。

```
X = Σ I(第 k 张在原位)；E[I]=P=1/52
E[X] = 52 × 1/52 = 1
```

不需要知道相关性——线性期望直接加。

**例 2｜掷骰子到 6 的期望次数**

Geometric(p=1/6) → E=1/p=6。

**例 3｜随机排列中 A 站在 B 前面？**

对称性 → 1/2。（更一般：A、B、C 三人相对顺序随机，A 在 B 前且 B 在 C 前 → 1/6。）

**例 4｜两个独立 U(0,1) 的最大值期望**

```
P(max ≤ x) = x²  →  E[max] = ∫₀¹ (1 − x²) dx = 2/3
```

推广：n 个均匀随机数的最大值期望 = n/(n+1)（见 [05 章次序统计量图](05_联合分布协方差与条件期望.md)）。

## 面试题

**热身**

1. 公平骰子 E[X]、Var[X]？ → 3.5 与 35/12。
2. E[X²] 与 E[X]² 谁大？ → Jensen：E[X²]≥E[X]²（等号仅常数）。

**核心**

3. n 顶帽子错配期望个数？ → 1（指示变量，与 n 无关）。
4. 随机取两个数（不放回，1..n），差的期望？ → 用对称性 E[|X−Y|]=(n²−1)/3n。
5. 掷硬币直到出现正面，期望次数？ → 2（几何 p=1/2）。

**进阶**

6. 圣彼得堡悖论：奖金 2^k、概率 2^(−k)，期望？ → 无穷大（E=1+1+...），现实靠效用/封顶。
7. X 有放回抽两次，min 的期望？ → 对称性 E[max+min]=E[X]+E[X]；或直接 E[min]=E[X]−E[max]+E[X]...（标准做法：P(min≤x)=1−(1−F(x))²）。
