# 04 大数定律与中心极限定理（LLN / CLT）

> 来源：[S2] Q2 大数定律与 CLT｜ [S7] Blitzstein & Hwang Ch5、绿皮书
> 用途：几乎所有"显著性"问题的理论根基——IC 的 t 统计、回测均值的置信区间、Monte Carlo 收敛。

## 概念

- **大数定律（LLN）**：X₁...Xₙ 独立同分布且 E[X]=μ，则样本均值 X̄ₙ → μ（依概率收敛）。
- **中心极限定理（CLT）**：独立同分布、方差 σ² 有限，则

```
(X̄ₙ − μ) / (σ/√n)  ⇒  N(0, 1)
```

- **标准误**：SE = σ/√n——均值估计的不确定性。
- 前提：独立（或弱依赖）+ 方差有限；**肥尾收敛慢**，方差不存在时 CLT 不适用。

## 金融应用（必背）

1. **IC 显著性**：对 T 期 IC 序列，t 统计 = mean(IC) × √T / std(IC)。这就是 CLT 在因子研究里的直接使用。
2. **回测均值置信区间**：策略平均收益 ± 1.96 × std/√n。
3. **Monte Carlo**：模拟次数越多，估计越准（误差 ~ 1/√n）。

## 小实验

```python
import numpy as np
rng = np.random.default_rng(0)
for n in [10, 100, 1000, 10000]:
    x = rng.uniform(0, 1, size=n).mean()
    print(n, round(x, 4))   # 越接近 0.5，且波动越窄
```

再多一步：重复采样 1000 次均值，画直方图，会看到它越来越像正态（即便原始分布是均匀/指数）。

## 面试题

1. 抛 100 次公平硬币，正面比例近似什么分布？ → N(0.5, 0.5²/100)，即 N(0.5, 0.0025)。
2. 为什么量化研究里的 t 统计"几乎都是正态假设"？ → CLT：样本均值/IC 均值在大样本下近似正态。
3. 厚尾收益下 CLT 还成立吗？ → 方差有限则成立但收敛慢；方差无限（如某些 α<2 的稳定分布）不适用。
4. 一个策略平均日收益 0.1%、日波动 1%，252 天后累计收益的均值与波动？ → 均值 25.2%，波动 15.9%（√252×1%）。
