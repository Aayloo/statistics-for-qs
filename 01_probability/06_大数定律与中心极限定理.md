# 06 大数定律与中心极限定理（LLN / CLT）

> 面试权重：★★★★☆ ｜ 难度：中 ｜ 来源：[S2 Q2][S7] Blitzstein & Hwang Ch5
> 定位：一切"显著性检验"的理论根基——IC 的 t 统计、回测置信区间、Monte Carlo 全靠它。

## 教学

**两个定理**

```
LLN: X̄ₙ = (X₁+...+Xₙ)/n → μ（依概率收敛）
CLT: (X̄ₙ − μ)/(σ/√n) ⇒ N(0,1)，当 n 大
SE = σ/√n（均值的标准差）
```

**条件**：独立同分布 + 方差有限；肥尾时收敛慢；方差不存在（柯西）不适用。

![CLT 收敛](assets/clt_convergence.png)

哪怕原始分布是均匀/指数，样本均值的分布也会迅速变正态——这是量化里"几乎处处用正态近似"的依据，也是"必须检查样本量够不够"的原因。

## 例题精讲

**例 1｜抛 100 次硬币**

正面比例 X̄ ~ N(0.5, 0.25/100)，P(0.4<X̄<0.6) ≈ 95.45%（±2SE）。

**例 2｜IC 的 t 统计（必背，面试直接考）**

T 期 IC 序列 {IC₁..IC_T}：

```
t = mean(IC) × √T / std(IC)
```

|t|>2 才认为因子显著——这行式子就是 CLT + 假设检验。

**例 3｜Monte Carlo 收敛**

模拟 10⁴ 次 → 误差 ~ σ/√n；样本量 ×4，误差减半。

## 面试题

**热身**

1. 抛 100 次硬币，正面比例的近似分布？ → N(0.5, 0.0025)。
2. 标准误是什么？ → 样本均值的标准差 σ/√n。

**核心**

3. 为什么 IC 检验用 t=mean·√T/std？ → CLT：大样本下均值统计量近似正态。
4. 样本量翻倍，置信区间宽度怎么变？ → 除以 √2 ≈ 0.707 倍。
5. 年化：日波动 1%，252 日总波动？ → 15.9%（√252，方差可加）。

**进阶**

6. 厚尾数据用 CLT 的风险？ → 收敛慢；若方差不存在则不收敛（柯西）。
7. 回测里均值估计不可靠时怎么办？ → bootstrap/block bootstrap（接 04 模块），或用稳健标准误。
8. CLT 需要 i.i.d. 吗？ → 弱依赖（mixing）也成立，但有序列相关时要用 HAC 标准误。
