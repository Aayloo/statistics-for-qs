# 04 降维与因子（PCA / SVD）

> 面试权重：★★★☆☆ ｜ 难度：高 ｜ 来源：[S2 Q8][S3 T4][S7]
> 定位：资产/因子太多时压缩信息——PCA 是统计因子模型的引擎。

## 一、教学

### 1.1 SVD 与 PCA

**SVD**：任意矩阵 X = U·Σ·V′，Σ 对角线是奇异值。

**PCA**：对协方差矩阵做特征分解，找方差最大的正交方向：

$$\Sigma v_j = \lambda_j v_j, \qquad \lambda_1 \ge \lambda_2 \ge \cdots$$

第 j 主成分 = 数据在 vⱼ 上的投影；第 j 主成分解释的方差比例 = λⱼ / Σλᵢ。

> 几何直觉：PCA 把高维数据旋转到"方差最大"的新坐标系，前几个轴就抓住主要结构。

### 1.2 PCA 与因子模型

- **经济因子**：由经济学先验指定（市场、价值、动量）——Fama-French。
- **统计因子**：由数据学出（PCA 主成分）——eigenportfolio。
- 两者互补：PCA 做降噪/结构发现，经济因子做解释。

### 1.3 在量化里的三个用途

1. **降噪**：前 k 个主成分重建收益率矩阵，滤掉噪声
2. **去冗余**：因子高度相关 → 用 PCA 找正交方向
3. **eigenportfolio**：主成分本身就是市场中性组合，学术常用

## 二、例题精讲

**例 1｜PCA 解释方差**

30 个资产的协方差矩阵，前 3 个特征值占 85% 总方差 → 3 个主成分即可近似整个市场结构。

**例 2｜主成分与市场因子**

美股横截面收益第一主成分通常与市场收益高度相关（市场因子是统计上的"第一根轴"）。

**例 3｜PCA 去噪**

50 个因子，两两相关 0.9 → 有效维度远小于 50 → 用前 10 个主成分替代原因子，回归更稳定。

## 三、面试题

**热身**

1. PCA 找什么？ → 方差最大的正交方向（特征向量）。
2. 特征值代表什么？ → 对应方向的方差。

**核心**

3. 怎么选主成分个数？ → 累计解释方差（如 ≥80%）、碎石图、特征值 >1。
4. PCA 需要标准化吗？ → 通常要，否则量纲大的变量主导。

**进阶**

5. PCA 与因子模型的区别？ → 经济先验 vs 数据驱动。
6. eigenportfolio 是什么？ → 主成分权重构造的组合。
7. PCA 对异常值敏感吗？ → 敏感，协方差估计被污染 → 先稳健化。
