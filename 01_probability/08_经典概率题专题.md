# 08 经典概率题专题（面试高频原题精讲）

> 面试权重：★★★★★ ｜ 难度：中→高 ｜ 来源：[S1][S7] 绿皮书、Heard on the Street、Joshi
> 定位：这些题几乎每个量化面试都会遇到。每题按"思路 → 推导 → 答案"精讲，练到能默写。

## 1. 生日问题

- **思路**：转互补事件——所有人生日都不同。
- **推导**：P(无重复)=365·364·...·(365−n+1)/365ⁿ。
- **答案**：n=23 → ≈50.7%；n=50 → ≈97%。直觉在"对子数" C(n,2)。

## 2. Monty Hall

- **思路**：初始选错概率 2/3，主持人开门不改变这点，换门赢 = 初始选错。
- **答案**：换门 2/3，不换 1/3。

## 3. 两孩子问题

- **样本空间**：{BB, BG, GB, GG}。
- **"至少一个男孩"** → 只剩 3 个 → P(BB)=1/3。
- **陷阱**：若问"随机点到一个孩子是男孩，另一个呢" → 1/2（条件不同）。

## 4. 赌徒破产

- **思路**：鞅/一阶差分方程。
- **答案**：公平游戏 P(赢到 N)=i/N；有偏见 [07 章](07_随机游走与鞅.md) 公式。

## 5. 集卡问题（Coupon Collector）

收集 n 种卡，每次随机得一种，集齐期望次数：

```
E = n·Hₙ = n(1 + 1/2 + ... + 1/n)
n=6 → 14.7 次；n=10 → 29.3 次
```

思路：已收集 k 种时，抽到新卡概率 (n−k)/n，期望等待 n/(n−k)，求和。

## 6. 圣彼得堡悖论

- **游戏**：掷到正面为止，奖金 2^k。
- **推导**：E=Σ 2^k·2^(−k)=∞。
- **答案**：期望无穷，但没人愿付大价钱玩 → 效用函数/财富约束解释。

## 7. 两信封悖论

- **问题**：两信封一个双倍金额，你拿到 X，换不换？
- **答案**：换不换对称，期望相同；"E[另一封]=1.25X"的推理假设了错误先验。

## 8. 错排问题（帽子/信与信封）

- **推导**：Dₙ = n!·Σ(−1)^k/k!。
- **答案**：P(全错)=Σ(−1)^k/k! → 1/e ≈ 36.8%（与 n 无关）。

## 9. 洗牌固定点

- **思路**：指示变量。
- **答案**：期望固定点数 = 1（任意牌数）。

## 10. 伯特兰盒

- **问题**：三盒（金金/金银/银银），取出一枚是金，同盒另一枚？
- **答案**：2/3（金球有三个等可能来源，两个在同金盒）。

## 自测（每题 2 分钟口头）

1. 23 人生日 → ≈50%。 2. Monty Hall → 2/3。 3. 两孩子 → 1/3。 4. 集卡 6 种 → 14.7。 5. 错排 → 1/e。 6. 伯特兰盒 → 2/3。 7. 固定点 → 1。 8. 圣彼得堡 → ∞。
