# 02 条件概率与贝叶斯定理

> 面试权重：★★★★★（几乎必考）｜ 难度：中 ｜ 来源：[S1][S2 Q1][S7] Blitzstein & Hwang Ch2-3
> 定位：量化面试第一高频考点；也是"信号 → 信念更新"的思维原型，后面整个回测严谨性模块都靠它。

## 教学

**核心公式**

```
P(A|B) = P(A∩B) / P(B)                   条件概率
P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A)      乘法法则
P(A)   = Σ P(A|Bᵢ)·P(Bᵢ)                 全概率公式（Bᵢ 互斥且覆盖）
P(A|B) = P(B|A)·P(A) / P(B)              贝叶斯定理
```

**四个词（面试要能脱口而出）**

- 先验 P(A)：看到数据前的信念（基准率）。
- 似然 P(B|A)：假设为真时，数据出现的概率。
- 证据 P(B)：数据在所有可能假设下的加权平均。
- 后验 P(A|B)：看到数据后更新过的信念。

**独立 ≠ 条件独立**：事件独立但给定 C 后可能相关（经典反例：两起火灾都受天气影响）。

**贝叶斯树（疾病检测）**：患病率 1%、检测敏感度 99%、特异度 99%：

![贝叶斯树](assets/bayes_tree.png)

```
P(患病|阳性) = 0.99×0.01 / (0.99×0.01 + 0.01×0.99) = 50%
```

直觉：阳性的人里，一半是"患病且检对"，一半是"健康且误报"——敏感度和特异度相同时恰好抵消。

## 例题精讲

**例 1｜两枚硬币，一枚公平一枚双正面。随机取一枚抛一次出正面，是双正面那枚？**

```
P(双正|正) = 1×(1/2) / [1×(1/2) + (1/2)×(1/2)] = 2/3
```

**例 2｜策略信号更新（量化视角）**

先验 P(有 alpha)=10%；有 alpha 时命中率 60%，无 alpha 时运气命中率 50%。看到一次命中后：

```
P(alpha|hit) = 0.6×0.1 / (0.6×0.1 + 0.5×0.9) ≈ 11.8%
```

结论：单次命中几乎不更新信念 → 量化研究才需要大样本 + 多重检验，而不是看一两个漂亮数字。

**例 3｜Monty Hall（换门）**

先选 A。主持人开一扇羊门后，P(车在另一扇没开的门) = P(车在 B∪C) = 2/3 → 换门赢率 2/3。

## 面试题

**热身**

1. P(A∪B) 用条件概率表示？ → P(A)+P(B)−P(A∩B)。
2. 三张牌：两面红、两面蓝、一红一蓝，随机抽一张只见一面是红，另一面也红？ → 2/3（不是 1/2）。

**核心**

3. Monty Hall 换门概率？ → 2/3（固定初始选错概率 2/3）。
4. 两孩子问题：已知"至少一个男孩"，两个都男孩？ → 1/3（样本空间 {BB,BG,GB}）。
5. 患病率 0.1%、敏感度 99%、特异度 99%，阳性后患病？ → ≈9%（上例敏感度≠特异度版）。

**进阶**

6. 伯特兰盒（三盒两币）→ 金盒取金后同盒再取金 = 2/3。
7. 先验是连续分布时贝叶斯怎么算？ → P(θ|数据) ∝ P(数据|θ)·P(θ)，归一化即可（贝叶斯推断入口）。
