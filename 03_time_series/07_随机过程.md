# 07 随机过程（GBM / OU / 泊松）

> 面试权重：★★★☆☆ ｜ 难度：高 ｜ 来源：[S2 Q14][S7] Tsay Ch1
> 定位：从"离散时间序列"到"连续时间过程"——资产定价的数学语言。

## 一、教学

### 1.1 几何布朗运动（GBM）

$$dS_t = \mu S_t\,dt + \sigma S_t\,dW_t$$

解：ln Sₜ = ln S₀ + (μ − σ²/2)t + σ·Wₜ，即价格对数正态。

> 这是 Black-Scholes 的基础假设：收益正态、价格对数正态。

### 1.2 伊藤引理（一句话直觉）

对随机过程的函数求导多一项二阶项（σ²/2）——因为布朗运动二阶变差不为零。期权定价里的"Δ 对冲"就是消掉这一项。

### 1.3 Ornstein-Uhlenbeck（OU）过程

$$dX_t = \theta(\mu - X_t)dt + \sigma\,dW_t$$

均值回复：偏离 μ 会被 θ 拉回；θ 越大回复越快。

> 用途：利率建模（Vasicek）、价差建模（配对交易）、隐含波动率均值回复。

### 1.4 泊松过程与跳跃

在连续时间框架里加离散跳跃：资产价格 = 扩散 + 跳跃项（Merton 跳跃扩散）。间隔 Exp(λ)，与 01 模块 12 章衔接。

### 1.5 与量化的连接

- 模拟路径（Monte Carlo 定价/回测）
- regime 的连续时间版本（转换扩散）
- 随机波动率（Heston）

## 二、例题精讲

**例 1｜GBM 离散模拟**

$$S_{t+1} = S_t \cdot e^{(\mu - \sigma^2/2)\Delta t + \sigma\sqrt{\Delta t}\,z}$$

回测/定价的标准模拟公式。

**例 2｜OU 半衰期**

θ = 0.4 → 半衰期 = ln2/0.4 ≈ 1.7 期——价差多久回复一半。

**例 3｜为什么均值项是 μ − σ²/2**

对数收益的漂移要减去波动修正，否则模拟的几何平均会系统性偏高。

## 三、面试题

**热身**

1. GBM 是什么？ → 几何布朗运动，价格对数正态。
2. OU 的特征？ → 均值回复。

**核心**

3. 为什么用对数正态？ → 价格非负、收益可加。
4. 伊藤引理多出的项？ → σ²/2 二阶项。
5. OU 的 θ？ → 回复速度。

**进阶**

6. GBM 漂移为什么是 μ−σ²/2？ → 对数变换的 Itô 修正。
7. 怎么模拟跳跃？ → 泊松过程驱动离散跳跃项。
