# 03 分层模型

> 面试权重：★★☆☆☆ ｜ 难度：高 ｜ 来源：[S7] Gelman BDA3 Ch5
> 定位：多个相关组（多资产、多因子、多策略）共享信息——部分池化。

## 一、教学

### 1.1 三种池化

- **完全池化**：所有组共用一个参数（忽略差异）
- **不池化**：每组独立估计（忽略共性，小样本方差大）
- **部分池化（分层）**：组间共享先验，自动收缩——最优折中

### 1.2 分层模型结构

$$\alpha_i \sim N(\mu_\alpha, \sigma_\alpha^2), \qquad y_{it} \sim N(\alpha_i, \sigma^2)$$

组参数 αᵢ 本身来自一个超先验——数据少的组被拉向整体均值。

### 1.3 在量化里的应用

- **多资产波动率**：各资产共享波动超先验，小样本资产被收缩
- **多因子 alpha**：同一逻辑族因子共享先验 → 自动多重检验校正
- **多策略绩效**：收缩极端样本外表现（对过拟合天然防御）

## 二、例题精讲

**例 1｜少数据组收缩**

10 只股票估计各自 alpha：只有 20 天数据的股票，分层后估计被拉向行业均值，比独立 OLS 稳。

**例 2｜分层 = 正则化**

分层先验等价于岭回归式收缩——面试可以这样类比。

**例 3｜与多重检验的关系**

分层共享先验 = 贝叶斯版"有效试验数"思维：组间相似 → 惩罚自动调整。

## 三、面试题

**热身**

1. 部分池化是什么？ → 组间共享信息 + 保留组差异。
2. 超先验？ → 组参数的先验的参数。

**核心**

3. 分层对少样本组的作用？ → 收缩到整体均值。
4. 与正则化类比？ → 类似岭回归收缩。
5. 为什么量化里有用？ → 抗过拟合、自动校正。

**进阶**

6. 什么时候分层不合适？ → 组间差异极大且样本充足。
7. 分层 vs 贝叶斯收缩？ → 同一思想，分层是结构化实现。
