# 03 条件概率与贝叶斯定理

> 来源：[S1] k3vv0（Probability）｜ [S2] Q1 条件概率与贝叶斯｜ [S7] Blitzstein & Hwang Ch2-3
> 用途：量化面试概率题的绝对高频；也是"信号更新"思维的基础——先验 × 似然 → 后验。

## 概念

- **条件概率**：P(A|B) = P(A∩B) / P(B)，前提 P(B)>0。
- **乘法法则**：P(A∩B) = P(A|B)·P(B)。
- **全概率公式**：若 B_i 互斥且覆盖全空间，P(A) = Σ P(A|B_i)·P(B_i)。
- **贝叶斯定理**：

```
P(A|B) = P(B|A)·P(A) / P(B)
       = P(B|A)·P(A) / [P(B|A)·P(A) + P(B|Aᶜ)·P(Aᶜ)]
```

- 术语：P(A) 先验（基准率）→ P(B|A) 似然（信号在"真"下的表现）→ P(A|B) 后验（看到信号后更新）。

## 交易 / 研究中的直觉

**问题**：你怀疑某策略有真实 alpha。先验 P(有 alpha)=10%；有 alpha 时信号命中率 60%，无 alpha 时纯运气命中率 50%。看到一次命中后，P(有 alpha | 命中) 是多少？

```
P(alpha|hit) = 0.6×0.1 / (0.6×0.1 + 0.5×0.9)
             = 0.06 / 0.51 ≈ 11.8%
```

结论：一次"命中"几乎不改变信念——这正是为什么回测需要大量样本和多重重检验，而不是看一两个漂亮数字。

## 经典题

1. **疾病检测**：患病率 0.1%，检测敏感度 99%、特异度 99%。检测阳性后真实患病概率？
   P(病|+) = 0.99×0.001 / (0.99×0.001 + 0.01×0.999) ≈ 9%。
2. **Monty Hall**：三扇门，主持人开一扇羊门后，换门赢的概率 = 2/3。
3. **两孩子问题**：已知"至少有一个男孩"，两个都是男孩的概率 = 1/3（不是 1/2）。

## 面试题

1. 一个检测的假阳性率 5%，患病率 1%，敏感度 100%，阳性后患病概率？ → 0.01/(0.01+0.05×0.99) ≈ 16.8%。
2. 两枚硬币一枚公平一枚双正面，随机取一枚抛出正面，是双正面那枚的概率？ → 2/3。
3. 策略命中率 55%，但你同时测试了 50 个策略——先验该下调多少？（引出多重检验）
